Connect this device

This board reads its data from a private GitHub repository. Paste a read-only token once on each device; it is kept in this browser only and sent only to GitHub.

  1. Open GitHub → New fine-grained token. Resource owner: your account.
  2. Repository access: choose Only select repositories (not the default “Public repositories”) and select — the one whose name ends in -data. The similarly named repository without “-data” holds only this page and has no data.
  3. Permissions → Repository permissions → Contents → Read-only (Metadata turns read-only by itself). Pick an expiry, generate, and paste the token here.
  4. Already made a token? Edit it in GitHub → Fine-grained tokens; the token value stays the same.
