# Proposal board

A single-page board for tracking grant and proposal work. This repository holds only the page; it contains no data.

On first visit the page asks for a GitHub fine-grained token with read-only Contents access to the private data repository. The token stays in that browser's local storage and is sent only to `api.github.com`. "Forget the token on this device" removes it.

The page is generated by `portfolio/tools/portfolio.py publish` from a private working folder; edit the template there, not here.
